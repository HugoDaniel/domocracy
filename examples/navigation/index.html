A navigation component that makes components

Two navigation bars are built from one spec. Each list is a region, and the adapter of a list creates entries, which create the lists under them. The recursion is components creating components: domocracy sees one container at a time and never learns that a menu is involved.

Who owns what

  • The region owns which entry hosts a list holds and in which order. Everything that changes them is an insert, a move, an update or a remove.
  • The entry component owns its link or button, the text node holding its label, its icon slot and whether its submenu is open. Those are private, so an update renames an entry without replacing the control the reader is focused on.
  • The page owns what a command means. An entry dispatches nav:select from the nav element and this page decides what to do with it, which is why the same component works in a page with other commands.

What to try

  1. Open Products, then Tools, then activate Export. The status line below says which navigation asked for it.
  2. Click directly on an icon. It behaves as a click on the label, because the delegated rule matches the nearest button above the target.
  3. Press Tab through the bar. A hidden submenu takes no focus. Press Escape inside an open submenu: it closes and focus returns to the button that opens it.
  4. Use the demonstration strip to add an entry to the open Tools submenu, rename it, toggle its icon, move it up and remove it. The new entry needs no new listener: the rules registered on the nav element already cover it.
  5. Watch Navigation B while you do all of that. Two instances of one spec share no state and no DOM ids.

Limits

This is a disclosure navigation, not a desktop menu bar. Enter and Space activate the disclosure buttons because they are buttons, Tab follows the native order, Escape closes the nearest open submenu, and a link stays a link. There is no arrow-key menu system, no roving tabindex and no application menu role. Changing an entry's kind after creation is not supported: remove it and add the kind you want.
